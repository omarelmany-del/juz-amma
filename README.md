# رفيق جزء عمّ

صفحة مجانية للعائلات لحفظ جزء عمّ مع الأطفال: تلاوة حقيقية بأربعة أصوات،
تشغيل وترديد كل آية لوحدها، هدف يومي صغير، ومتابعة الحفظ على الجهاز.

## المصادر والحقوق

- النص القرآني: Tanzil Quran Text (Uthmani, Version 1.1) — Copyright (C) 2007-2021
  Tanzil Project — Creative Commons Attribution 3.0 — https://tanzil.net
  منقول حرفيًا بدون أي تغيير (surahs.js).
- التلاوات على مستوى السورة (تُشغَّل من خوادم المصادر مباشرة لحظة الاستماع، لا تُخزَّن هنا):
  - محمود خليل الحصري والحسيني العزازي (المعلم مع الأطفال) — QuranicAudio.com
    (Quran Foundation)، مع النسب للمؤسسة والقارئ.
  - محمد البراك ومحمد صديق المنشاوي (المصحف المعلم) — MP3Quran.net.
- التشغيل آية بآية (ملف صغير لكل آية، عبر واجهة Quran.com وخوادم QuranicAudio،
  بنفس شروط النسب):
  - الحصري المعلم (Husary_Muallim_128kbps) — يُستخدم للترديد آية بآية مع خياري
    «الحصري مع الأطفال» و«العزازي مع الأطفال» لأنه لا يوجد تسجيل آية بآية بنسختي الأطفال.
  - مشاري العفاسي — يُستخدم مع خيار «محمد البراك» لعدم توفر تسجيل آية بآية للبراك.
  - المنشاوي المجوّد — يُستخدم مع خيار «المنشاوي المعلم» لعدم توفر ملفات آية بآية
    لنسخة المصحف المعلم.
- الخطوط: Amiri Quran وIBM Plex Sans Arabic — SIL Open Font License.

## ملاحظات تقنية

- موقع ثابت بلا خطوة بناء: افتح index.html مباشرة أو انشره كما هو.
- التقدم (النجوم والعلامات وهدف اليوم) يُحفظ محليًا على جهاز المستخدم فقط (localStorage)،
  ولا يُمسح بمرور الأيام.
- التكرار آية بآية: ١ أو ٣ أو ٥ مرات، مع خيار سرعة أبطأ (٠٫٧٥×) على ملف الآية فقط.
- لا تُجمع أي بيانات ولا تُرسل أي طلبات خارج مصادر الصوت الرسمية.
